# ✧XE・PON♡✧ // Official Cyber Portal

Official web portal and interactive cyber player for **✧XE・PON♡✧** (ゼ・ポン), the Japanese Post-Hardcore & Alternative Rock 4-piece idol/rock group.

Stream the 5 original tracks from ***NEON & FRICTION*** directly in your browser with high-resolution audio, explore Tokyo filming locations and sound profiles, view uncropped photo archives with floating Picture-in-Picture mode, and dive into the full 16-song discography on [Phase](https://app.phase.app.br/?artist=a02db54f-13c9-4c9f-bb95-4b505880dcc2).

---

## ⚡ Live Features

- 🎧 **In-Browser Audio Player**: Full playback controls, real-time waveform visualizer, scrubber timeline, volume slider, and persistent bottom cyber dock.
- 📜 **5-Track Sound Profile Showcase**: Curated rock journalism and production directions for all 5 songs:
  1. **ASTRAL SHIBUYA OVERDRIVE** (3:34) — *Shibuya Scramble & Center-Gai, Tokyo*
  2. **ZANGAI** (3:30) — *Shinjuku Omoide Yokocho & Underpass, Tokyo*
  3. **BREAK THE LIMIT#1** (3:26) — *Shimokitazawa Underground Livehouse, Tokyo*
  4. **HIBANA** (3:25) — *Akihabara GiGO Rooftop & Electric Town, Tokyo*
  5. **BREAK THE LIMIT#2 ★** (3:45) — *Shibuya Back-Alley Street Food Stall, Tokyo* [Featured Climax Single]
- 📸 **Photo Gallery & Picture-in-Picture**:
  - Click any band photo to open a **full uncropped lightbox modal** (`object-fit: contain` ensures all 4 members remain completely visible).
  - Click **`🗕 MINIMIZE`** to tuck the photo into a **floating cyber mini-viewer** in the corner so you can keep looking at the picture while scrolling and listening to music.
  - Keyboard navigation (`ESC` to close, `←` / `→` to flip photos, `M` to minimize).
- 🎬 **Toei Animation Lore**: Widescreen artwork showing all 4 girls kneeling in Shinjuku shocked at 108+ incoming calls from Toei Animation producers desperate to license the chorus of *BREAK THE LIMIT#2* for their fall anime season.
- 🌐 **100% Bilingual Engine**: Instant English (EN) and Japanese (JA) toggle with complete parity across all 79 UI keys, lyrics, locations, and terminal logs.
- ⚡ **Phase Discography Callout**: Direct deep links to the band's complete **16-song catalogue** streaming on the official Phase platform.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible structure with micro-animations.
- **CSS3**: Custom Cyberpunk glassmorphism design system (`#ff61a6` neon pink, `#70e0ff` baby blue, dark HUD backdrop). Zero heavy frameworks.
- **Vanilla JavaScript**: Lightweight audio engine, interactive track showcase tabs, lyrics modal, photo lightbox with PiP minimize dock, and bilingual i18n engine.
- **GitHub Pages Ready**: Static website with zero build steps required.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/marcuscaiado/xe-pon-official.git

# Navigate into project directory
cd xe-pon-official

# Start any local HTTP server (e.g. Python)
python -m http.server 8088

# Open http://localhost:8088 in your browser
```
